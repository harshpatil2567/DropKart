# DropKart - A Decentralized Peer-To-Peer Hyperlocal Delivery App For Public Welfare 
🔍 <b>Brief Project Description</b>

DropKart is a decentralized, peer-to-peer hyperlocal delivery platform that empowers individuals to send and deliver packages in their neighborhood — without relying on centralized, commission-heavy platforms.

With a mobile-first, real-time interface, anyone can become a sender or a delivery agent. Small tasks like sending lunch to school, delivering forgotten keys, or moving documents across town can now be completed quickly, affordably, and directly — by people in the community.

Built as a Progressive Web App (PWA) with a focus on speed, simplicity, and decentralization, DropKart connects people — not platforms.

🌟 <b><u>Key Features</u></b>
🔐 <b>Phone-Based OTP Authentication</b>

Passwordless login using mobile number + OTP

Built with Supabase Auth for quick, secure access

Demo mode: 6-digit OTP for hackathon testing

🔄 <b>Dual-Role System: Sender or Rider</b>

Upon login, users choose:

“I need a delivery” (Sender)

“I can deliver” (Rider)

Seamless switch between roles

📝 <b>Task Creation (Sender)</b>

Fill out a simple 4-field form:

Pickup address

Drop-off address

Package description

Suggested delivery fee

Tasks appear as OPEN for nearby riders

🗺️ <b>Task Discovery (Rider)</b>

Live map powered by Leaflet.js

Shows all OPEN tasks in real time

Tapping a task shows summary + accept option

🔄 <b>Task Lifecycle Management</b>

Riders can update delivery status:

OPEN → ACCEPTED → IN_TRANSIT → COMPLETED

Real-time sync for sender and rider using Supabase Realtime

📍 <b>(Optional) Real-Time Location Tracking</b>

Rider’s location updates during delivery

Sender can track the progress on a live map

⭐ <b>Community Rating System</b>

After delivery, both parties rate each other (1–5 stars)

Ratings build trust and reputation over time

🌍 <b><u>Impact</u></b>
🧑‍🤝‍🧑 <b>Empowers Communities</b>

Turns ordinary people into delivery agents

Encourages local micro-economies through gig-style work

🏪 <b>Supports Small Businesses</b>

Offers an affordable delivery alternative

Avoids reliance on commission-heavy platforms like Uber Eats or Dunzo

🚀 <b>Reduces Latency in Local Delivery</b>

Leverages real people in the area to fulfill tasks faster than traditional methods

🌱 <b>Promotes Sustainable, Local Logistics</b>

Encourages low-emission, hyperlocal movement (e.g., foot, bike delivery)

Reduces the need for centralized fleets or warehouses
